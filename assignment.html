My favourite coding language is C. I like this Fibanocci series problem. 

            
                #include <stdio.h>
                void printFib(int n) {
                    if (n < 1) {
                        printf("Invalid Number of terms\n");
                        return;
                    }
                
                    int prev1 = 1;
                    int prev2 = 0;

                    for (int i = 1; i <= n; i++) {
                        
                        if (i > 2) {
                            int curr = prev1 + prev2;
                            prev2 = prev1;
                            prev1 = curr;
                            printf("%d ", curr);
                        }
                        else if (i == 1)
                            printf("%d ", prev2);
                        else if (i == 2)
                            printf("%d ", prev1);
                    }
                }

                int main() {
                    int n = 9;
                    printFib(n);
                    return 0;
                }
  1. We can use one of the C loops to iterate and print the given number of terms.
  2. The first two terms, F1 and F2 should be handled separately.
  3. After that, we can use two variables to store the previous two terms and print the current term by adding these two.
  4. We have to keep updating the previous terms as we move to print the next term in the series.
